# Automated AWS EC2 Deployment

## Project Description
This project demonstrates how to automate the deployment of an Nginx web server on an AWS EC2 instance using a Bash script passed via User Data. 

## Technologies Used
* AWS EC2 (Ubuntu AMI)
* Bash Scripting
* Linux (Nginx Web Server)
* Git & GitHub
